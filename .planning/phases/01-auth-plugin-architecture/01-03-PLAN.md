## Phase Goal

**As an** integration operator, **I want** OAuth tokens cached centrally and Groovy scripts pre-compiled on connector publish, **so that** token reuse is correct across profiles and bad scripts fail before invoke (D-08, D-19, D-20, D-21; partial AUTH-01 via existing OAuth built-ins).

<objective>
Centralize OAuth token caching and wire publish-time script compilation + token eviction hooks.

Purpose: Fix per-provider cache key collision (PITFALLS #3); enforce compile-on-publish (D-08).
Output: TokenCache, refactored OAuth providers, ConnectorPublishListener integrated with ConnectorRegistry.
</objective>
