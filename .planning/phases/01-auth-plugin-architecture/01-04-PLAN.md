## Phase Goal

**As a** mapping script author (Phase 2), **I want** an immutable auth snapshot and outcome on every invoke result, **so that** downstream pipeline stages read tokens and signatures without re-fetching (AUTH-04, AUTH-05, D-10, D-11, D-12).

<objective>
Introduce AuthContextSnapshot, AuthConfigResolver for Groovy-only endpoint override, and wire carry-forward through DefaultIntegrationOrchestrator into InvocationResult.

Purpose: Prevent auth context loss before mapping (PITFALLS #2); structural AUTH-05 even before mapping module exists.
Output: Snapshot factory, orchestrator integration, unit tests proving snapshot readable without HTTP.
</objective>
