<objective>
Extend `DefaultIntegrationOrchestrator.invokeStream()` so streaming endpoints run the request side of the pipeline (mapRequest -> transform -> auth) before the stream opens — closing PIPE-04 while preserving SC#5 (no mapping buffer regression). Response chunks pass through raw; response mapping, if configured, is ignored with a warn-once. This slice reuses the request-side helper 03-01 builds for `invoke()`, so it depends on 03-01 and shares the orchestrator + integration-test files (Wave 2).

Purpose: The symmetry temptation (Pitfall 4) is to buffer streamed chunks to apply `mapResponse`, reintroducing the latency/memory regression SC#5 forbids. PIPE-04 keeps the request side rich and the response side a raw passthrough.
Output: A streaming-aware `invokeStream`, a pre-stream-failure unit test, and an SSE integration test proving request-side mapping + raw chunks + warn-once.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> streaming invoke endpoint | Inbound body crosses into the request-side pipeline before the stream opens; it must be the signed body. |
| vendor SSE stream -> ServletStreamingInvocationSink -> caller | Vendor chunks flow back raw; no transform/mapping is applied per chunk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering / Spoofing | `invokeStream` auth signing | mitigate | D-15/MAP-06: compute mapped+transformed `outboundBody` before `authenticate(...)` and before `httpTransport.exchangeStream`; SSE integration test asserts HMAC over the mapped body via WireMock `withRequestBody`. |
| T-03-09 | Denial of Service | streamed-chunk buffering to apply response mapping (SC#5 regression) | mitigate | D-16/Pitfall 4: chunks pass raw through `HttpStreamHandler.onLine`; no `StringBuilder` accumulation; warn-once (D-17) instead of buffering when response mapping is configured. |
| T-03-02 | Information Disclosure | DEBUG stage-timing / warn-once log in streaming path | mitigate | D-23: log stage name + millis and endpoint id only; the warn-once message names the endpoint, never logs request/response bodies or credentials. |
| T-03-06 | Information Disclosure | pre-stream failure surfaced to caller | mitigate | D-18/D-19/D-20: pre-stream typed exception throws before any chunk → `RuntimeApiExceptionHandler` structured error (no partial stream, no stack trace); post-start failures go to `sink.fail`. |
